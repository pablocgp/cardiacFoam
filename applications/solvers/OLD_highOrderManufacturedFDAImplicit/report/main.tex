\begin{abstract}
This report documents the manufactured-solution finite-volume solver \code{highOrderManufacturedFDAImplicit}. The solver advances the same manufactured FDA activation problem as the explicit code, but uses a high-order implicit matrix discretization for $V_m$ and a theta-type implicit update for the state variables. The convergence figures are generated by \code{plot\_convergence.m} from the data in \code{/home/pablo/OpenFOAM/pablo-v2312/run/tutorials\_electro/highOrderManufacturedFDAImplicit/results/example0/2D}.
\end{abstract}

\section{Manufactured FDA problem}
The exact solution and reaction terms are the same as in the explicit solver. The reported two-dimensional exact fields are
\begin{align}
F(x,y) &= \cos(\pi x)\cos(2\pi y), & G(x,y) &= 1+xy^2,\\
V_m^{\star} &= \sqrt{1+t}\,F, &
u_1^{\star} &= (1+t)G+V_m^{\star},\\
u_2^{\star} &= \frac{1}{(1+t)\sqrt{G}}, &
u_3^{\star} &= 0.
\end{align}
The parameter $\beta$ is computed from the conductivity tensor and the manufactured Laplacian mode so that the exact fields satisfy the coupled PDE--ODE system.

\section{High-order matrix discretization}
The implicit solver assembles a high-order mass matrix $M$ and stiffness matrix $K$ once during setup for the fixed mesh and constant conductivity. The mass matrix can be \code{lumped}, i.e. diagonal, or \code{consistent}, where the LRE reconstruction is integrated over the cell quadrature points. The stiffness matrix is assembled from LRE face-gradient coefficients and face quadrature. The current implementation requires \code{useHighOrder\_Vm=true}; the state source terms may use high-order LRE reconstruction through \code{useHighOrder\_states}.

After scaling by $1/(\chi C_m)$ and separating the manufactured linear beta term, the discrete potential operator is
\begin{equation}
L = \frac{1}{\chi C_m}K - \frac{\beta}{\chi C_m}M.
\end{equation}
The expected spatial orders used in the plots are $2$ for \code{p1}, $3$ for \code{p2}, and $4$ for \code{p3}.

\section{Implicit time integration}
The time integration uses a theta method, with
\begin{equation}
\theta=1 \quad \text{for backward Euler}, \qquad \theta=\frac{1}{2} \quad \text{for Crank--Nicolson}.
\end{equation}
The potential solve has the form
\begin{equation}
\left(\frac{M}{\Delta t}-\theta L\right)V_m^{n+1}
=
\left(\frac{M}{\Delta t}+(1-\theta)L\right)V_m^n
+ \theta(S^{n+1}+b^{n+1}) + (1-\theta)(S^n+b^n),
\end{equation}
where $S$ contains the nonlinear source contribution and $b$ contains the manufactured Dirichlet boundary contribution. Nonlinear coupling is handled by a fixed number of outer corrections, and the states are updated by a theta-consistent local implicit iteration. The linear system is solved with Eigen using either \code{SparseLU} or \code{BiCGSTAB}, according to \code{implicitHOCoeffs}.

\section{Error measures and convergence rates}
The reported errors are the same as in the explicit solver: cell-centred volume-weighted $L_1$, $L_2$, $L_\infty$, and Gauss-reconstructed norms. Pairwise rates are computed with consecutive mesh sizes and $h_N=1/N$. The summary table reports the all-mesh log--log fit of the cell-centred $L_2$ errors.

\section{Notes}
For the same spatial order, Crank--Nicolson should reduce the temporal contribution relative to backward Euler when the time step is not already negligible. The mass-matrix comparison isolates the effect of lumped versus consistent integration in the high-order potential solve.
