\subsection{Two-dimensional results: comments}
\label{sec:results-2d-conclusions}

The current 2D tables fix the time scheme and mass matrix to \code{crankNicolson} and \code{consistent}, and use \code{RKF45} for the state ODEs. The first column now records the full \code{Vm-states-Iion} triplet, so configurations that share the same voltage and ionic reconstruction but differ in state treatment are no longer collapsed into the same label.

Under this fixed discretisation, \code{Picard}, \code{diagonalIion}, and \code{JFNK} produce comparable observed convergence orders to the precision reported in the tables. The practical distinction in this MMS sweep is therefore computational cost and nonlinear robustness rather than asymptotic accuracy.

On the structured hexa mesh, the clearest high-order verification remains the higher-order voltage reconstructions paired with compatible state and ionic quadrature settings. The unstructured triangular mesh is more sensitive to the selected \code{Vm-states-Iion} triplet, the stabilisation parameter $\alpha$, and the time step.
