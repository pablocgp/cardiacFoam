\subsection{Three-dimensional manufactured problem}
The tables in this subsection collect the 3D results that are currently
available. The Picard, diagonal-$\Iion$, and JFNK sweeps live in separate
tutorial roots:
\begin{itemize}
\item \path{highOrderManufacturedFDAImplicitJfNK/results/example0/3D/} (\code{JFNK}),
\item \path{highOrderManufacturedFDAImplicitJfNK_diagonalIion/results/example0/3D/} (and \path{_1}),
\item \path{highOrderManufacturedFDAImplicitJfNK_Picard/results/example0/3D/} (and \path{_1}).
\end{itemize}
Fits use $N=10$--$30$ for the general order column and
$N=20$--$30$ for the asymptotic column, in line with the
coarser 3D mesh sweep $N\in[10,30]$. Missing rows correspond to
configurations that have not yet been completed or whose error file is
not yet aggregated.
